# Student Directory

A responsive React application that displays a searchable directory of students with status indicators, skill tags, and profile details.

## Features

* Display all students in a card-based layout
* Real-time search by student name
* Case-insensitive filtering
* Student count badge
* Color-coded status badges
* Skills displayed as individual tags
* View Profile button with student details
* "No students found" fallback message
* Responsive design using CSS Grid/Flexbox
* CSS Modules for scoped styling

## Technologies Used

* React
* Vite
* JavaScript (ES6+)
* CSS Modules

## Installation

```bash
npm create vite@latest student-directory -- --template react
cd student-directory
npm install
npm run dev
```
